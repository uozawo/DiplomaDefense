# Дипломний проект — моделювання підготовки та захисту

консольна програма на c#. показує як студент готує дипломний проект:
додає етапи, керівник їх приймає, призначається рецензент і потім захист.

## як запустити

потрібен .NET 8 SDK.

```
dotnet run
```

або відкрити `DiplomaDefense.csproj` у Visual Studio і натиснути запуск.

## дані

програма читає дані з текстових файлів у тій самій папці:
- `students.txt` — студенти
- `supervisors.txt` — керівники
- `reviewers.txt` — рецензенти
- `projects.txt` — проекти (створюється сам коли зберігаємо)

тексти меню лежать у `messages.json`.

## що всередині

- `Person` — базовий клас, від нього `Student`, `Supervisor`, `Reviewer`
- `Stage` і `UrgentStage` — етапи (показано успадкування)
- `DiplomaProject` — проект з етапами
- `IReportable` — інтерфейс для звіту
- свої винятки на різні помилки
- `DiplomaService` — робить всю роботу і зберігає у файли
